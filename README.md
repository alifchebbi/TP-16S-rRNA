# TP 16S rRNA – Bacterial Identification and Phylogeny

**Practical course in Microbiology / Phylogeny**
Institut Supérieur de Biotechnologie de Sidi Thabet (ISBST), Université de la Manouba, Tunisia

> ⚠️ **For teaching purposes only.** These files are provided only to support a university practical course (TP). They are not intended for research, clinical, diagnostic or commercial use.

## Description

In this practical, students identify bacteria from their **16S rRNA gene sequences** and place them in a phylogenetic context. Students:

1. Run **NCBI BLASTn** on unknown 16S rRNA sequences (*Strain 1*, *Strain 2*) to find their closest relatives.
2. Retrieve 16S rRNA sequences of **type strains** from recent new-species descriptions in *IJSEM* and download them from NCBI in **FASTA** format.
3. Add an **outgroup** sequence.
4. Align the sequences with **MUSCLE** in **MEGA 11**.
5. Build a **Neighbor-Joining tree** with bootstrap support (1000 replicates) and interpret it.
